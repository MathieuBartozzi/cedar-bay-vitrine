# Vitrine IA Cedar Bay

Simulation de l'atelier « Juin 2028 : comment en est-on arrivé là ? » pour les chefs d'établissement MLF Boston.

Le site présente quatre fournisseurs fictifs de plateformes IA (Correcta, Lumi, Veriscript, Concierge) et une table d'analyse par fournisseur, avec un dossier de huit pièces et une frise chronologique à reconstituer.

- Année affichée : modifiable dans `etat.json` (`2026` ou `2028`).
- Langue : anglais par défaut, bouton FR pour passer en français.

Usage interne, atelier d'animation.
